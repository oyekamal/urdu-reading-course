# Bar: printable practice sheets (round 11f)

References fetched 2026-10-03 (saved locally, gitignored, `.audit/improve/f_pdf/bar/`; study only, nothing copied):
1. **K5 Learning, "Tracing the Letter K"** https://www.k5learning.com/worksheets/kindergarten/tracing-letters-k.pdf (k5_k.pdf) - NAMED BAR.
2. **Belaraby Apps, "Tracing Arabic alphabet worksheets"** (15 pp, Arabic script, dotted letter, dot shown below) https://www.belarabyapps.com/wp-content/uploads/2020/10/tracing-arabic-alphabet-worksheets.pdf
3. **FIMS Schools / worksheetpoint, Urdu pre-writing "pencil pherain"** https://fimsschools.com/wp-content/uploads/2025/05/Urdu-Alphabets-Tracing-worksheet-1.png (Urdu school sheet: dashed paths, start dots, arrows)

Why K5 is the bar: single clear purpose per page; strict hierarchy (title, one-line instruction, model letter, practice rows); a 3-line writing guide (top, dashed midline, baseline) that matches a child's hand; numbered stroke arrows on the first model only; solid model then fading dashed guides then empty space; thin grey rules (low ink); footer. It has no clutter, no colour fill. Belaraby is the Arabic-script reference for dotted letters, dots handled last. FIMS shows the Urdu school norm (name/class/date fields, start dot + arrow) but is ink-heavy (full-bleed colour) and has no pedagogy.

Dimensions (judged blind per page type, A/B against the bar page of the same kind):
1. Print clarity: crisp vector, nothing tiny; guides legible when photocopied.
2. Tracing guides: start dot + direction arrow, body first, dots last, model then dotted then blank.
3. Spacing for a child's hand: line height >= 14 mm for ages 5-7, big letters (>= 25 mm).
4. Layout hierarchy: title > instruction > task; one job per page.
5. Ink-friendliness: white background, thin grey, one accent only.
6. Urdu typesetting: RTL order, joined forms right, no isolated forms where joins required, Naskh/Nastaliq, marks not clipped.
7. Pedagogy: body first, dots last; look-alikes by dot count; decodable words only from taught letters.
8. Answer keys: present, correct, not on the child's face.
9. Parent guidance: what to say, how long, how to check.
