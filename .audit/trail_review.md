## Attention (most important first)

1. **Fabricated-looking TTS numbers.** The 08:48 gauntlet-r2 row's headline metric ("Whisper chunk match on sentences 0.67→0.94, letter names 0.42→0.63-0.73") does not match its own cited source (`research/06_tts_bakeoff.md` shows 0.994→0.983 and 0.366→0.639), and the only file that *could* substantiate a different number (`assets/audio/verify.json`) doesn't exist. This is the headline evidence for switching the whole course's audio to a licence-ambiguous fine-tune — worth asking directly what these numbers were actually measured from before trusting the TTS swap decision.
2. **Licence exposure, correctly disclosed but easy to miss.** All audio (baseline and the shipped `sharjeel103` fine-tune) inherits Meta MMS's CC-BY-NC-4.0 (non-commercial) restriction; the fine-tune's own model card states no licence at all. README is honest about this ("Fine for a pilot; for a commercial client, record a native speaker"), but nothing gates the artifact-publish step on it — the 08:48 "deliver" row ships the artifact without re-flagging the licence question raised two rows earlier in the same tick.
3. **"Client deliverable" framing is unsupported.** No client is named anywhere (board task #60 says only "gauntlet loop"). If this becomes an actual client hand-off later, re-confirm who signed off on the TTS licence risk and the un-cited quality-bar sources before calling it deliverable.
4. **Missing `verify.json` means the audio-quality gate has never actually run to completion and left evidence.** `scripts/verify_audio.py` exists and is well-written, but its one output artifact is absent — meaning the "smoke test" claimed at multiple points (README, decisions row) is not currently backed by anything reproducible in the repo. Worth re-running before trusting the audio.
5. **`check_decodable.py`'s FOLD/exemption logic was flagged by round-2's own critic as a false-confidence risk, then fixed — but the two letters it exempts (آ, ؤ) still have no `letters.json` rows at all.** The gate now folds them to base letters instead of silently ignoring them, which is real progress, but the course still teaches آ/ؤ words (unit 6, 9, 10) without a canonical letter-data row for either — a genuine content gap `critic_round2_units.md` calls its #4-#5 remaining defects, not reflected as an open item in decisions.tsv.
6. **Stroke-order/tracing is admittedly the weakest surface and still text-only inference.** `critic_round2_units.md` item 3 explicitly says the STROKE dict's content is "unsourced model inference" with no `research/*.md` backing — this is taught as fact to a beginner (e.g., "کاف: cap stroke first") with no citation. Low-stakes for reading comprehension, real for handwriting instruction.
7. **Board task #60 is still `in_progress`** (`~/.kamil-harness/harness.db`, last updated 08:04) despite two full gauntlet rounds and a publish having happened since — the board and the actual state have drifted.
8. **Repo root has an untracked stray file (`empty`, 40 bytes) and several debug HTML/notes files under `.audit/`** that look like scratch output from critic Playwright sessions, not intentional deliverables — worth a cleanup pass before this repo is shown to anyone external.
